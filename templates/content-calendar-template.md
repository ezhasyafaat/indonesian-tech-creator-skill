# Content Calendar Template

## Quick Reference
- Plan 2-4 weeks ahead
- Balance: 60% educational, 30% tips/tricks, 10% personal/behind-the-scenes
- Cross-platform: Repurpose content across TikTok, YouTube, Instagram, Blog
- Best posting times (WIB): TikTok 19:00-21:00, YouTube 15:00-17:00, Blog Tue-Thu 09:00-11:00

## Posting Schedule

**TikTok:**
- Frequency: Daily or 5x/week
- Best times: 19:00-21:00 WIB (peak), 12:00-13:00 WIB (lunch)
- Duration: 15-60 seconds

**YouTube:**
- Frequency: 2x/week
- Best times: 15:00-17:00 WIB, 19:00-21:00 WIB
- Duration: 8-15 minutes

**Instagram:**
- Feed: 3-5x/week
- Stories: Daily
- Reels: 3-5x/week
- Best times: 12:00-13:00, 19:00-21:00 WIB

**Blog:**
- Frequency: 1-2x/week
- Best days: Tuesday, Wednesday, Thursday
- Best times: 09:00-11:00 WIB

**Twitter/X:**
- Frequency: Daily
- Best times: 08:00-09:00, 12:00-13:00, 19:00-21:00 WIB

## Cross-Promotion Strategy

**YouTube → TikTok:**
- Cut best moments into 15-60 second clips
- Add "Full tutorial di YouTube, link di bio"

**Blog → Twitter:**
- Convert key points into thread
- Link to full article

**TikTok → Instagram:**
- Repost TikTok as Reel
- Add Instagram-specific CTA

**All → Newsletter:**
- Weekly roundup of content
- Exclusive tips for subscribers
