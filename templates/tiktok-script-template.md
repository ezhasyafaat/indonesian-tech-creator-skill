# TikTok Script Template

## Quick Reference
- Duration: 15-60 seconds (sweet spot: 30-45 detik)
- Structure: Hook (3 detik) → Content (20-35 detik) → CTA (5 detik)
- Aspect ratio: 9:16 vertical
- Text overlay: Large, bold, easy to read

---

## Template

```
🎬 TIKTOK SCRIPT: [Judul]
Duration: [X] seconds | Style: [Casual/Educational/Entertaining]

[0-3 detik] HOOK
Visual: [Close-up ke kamera / text overlay besar / action shot]
Audio: "[Kalimat pembuka yang grab attention]"
Text overlay: "[Text besar di layar]"

[3-X detik] CONTENT PART 1
Visual: [Screen recording / demo / penjelasan]
Audio: "[Penjelasan part 1]"
Text overlay: "[Key point 1]"

[X-Y detik] CONTENT PART 2
Visual: [Lanjutan demo / contoh lain]
Audio: "[Penjelasan part 2]"
Text overlay: "[Key point 2]"

[Y-Z detik] CONTENT PART 3
Visual: [Result / summary / final demo]
Audio: "[Penjelasan part 3]"
Text overlay: "[Key point 3]"

[Final 5 detik] CTA
Visual: [Kembali ke kamera / text overlay CTA]
Audio: "[Call to action]"
Text overlay: "Follow @[username]"

---
📝 PRODUCTION NOTES:
- Background music: [Lo-fi beat / trending sound / original audio]
- Music volume: 15-25% (jangan terlalu keras)
- Caption: "[Caption dengan hashtags]"
- Post time: [Hari] [Jam] WIB
- Engagement: [Reply comments dalam 2 jam pertama]
```

## Example: Git Tips

```
🎬 TIKTOK SCRIPT: Git Tips Senior Dev
Duration: 45 seconds | Style: Casual educational

[0-3 detik] HOOK
Visual: Close-up ke kamera, ekspresi serius
Audio: "Kamu masih git add . setiap file? Senior dev nggak pernah gitu."
Text overlay: "STOP git add ."

[3-15 detik] TIP 1: git add -p
Visual: Screen recording terminal, ketik git add -p
Audio: "Pakai git add -p. Ini interactive staging. Kamu bisa pilih hunk mana yang mau di-commit. Jadi commit kamu bersih, nggak campur-campur."
Text overlay: "git add -p = selective staging ✅"

[15-27 detik] TIP 2: git commit --amend
Visual: Screen recording, demo amend
Audio: "Trus pakai git commit --amend. Lupa masukin file? Nggak perlu commit ulang. Amend aja, otomatis masuk ke commit sebelumnya."
Text overlay: "git commit --amend = fix last commit 🔧"

[27-40 detik] TIP 3: git stash
Visual: Screen recording, demo stash
Audio: "Terakhir, git stash. Butuh switch branch tapi kerjaan belum selesai? Stash dulu, nanti bisa di-apply lagi."
Text overlay: "git stash = save work in progress 💾"

[40-45 detik] CTA
Visual: Kembali ke kamera, senyum
Audio: "Follow untuk tips tech lainnya. Link di bio untuk tutorial lengkap."
Text overlay: "Follow @yourusername 🔥"

---
📝 PRODUCTION NOTES:
- Background music: Lo-fi coding beat, volume 20%
- Caption: "Git tips yang senior dev pakai 🔥 Save buat nanti! #DeveloperIndonesia #Git #Programming #CodingTips #TechIndonesia"
- Post time: Selasa 19:30 WIB
- Engagement: Pin comment "Mau tips apa lagi? Comment below!"
```

## Tips for Indonesian Audience

1. **Hook yang relate**: Pakai masalah yang sering dihadapi developer Indonesia
2. **Bahasa casual**: Seperti ngobrol sama teman, bukan presentasi formal
3. **Text overlay besar**: Banyak nonton tanpa suara, text harus jelas
4. **Contoh lokal**: Reference Gojek, Tokopedia, dll kalau bisa
5. **CTA yang jelas**: Suruh follow, save, atau comment
6. **Hashtag mix**: 3-5 Indo + 3-5 English + 2-3 niche
