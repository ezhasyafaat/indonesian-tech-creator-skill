## How to Contribute

We welcome contributions from everyone! Here's how you can help:

### 1. Report Bugs
- Open an issue describing the bug
- Include steps to reproduce
- Add screenshots if applicable
- Mention your environment (OS, agent platform)

### 2. Suggest Features
- Open an issue with the "enhancement" label
- Describe the feature and its benefits
- Provide examples if possible

### 3. Submit Pull Requests
1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Make your changes
4. Test your changes
5. Commit your changes (`git commit -m 'Add amazing feature'`)
6. Push to the branch (`git push origin feature/amazing-feature`)
7. Open a Pull Request

### 4. Improve Documentation
- Fix typos
- Add examples
- Translate to other languages
- Improve clarity

### 5. Add Templates
- Create new content templates (Twitter thread, LinkedIn post, etc.)
- Add workflow guides
- Share best practices

### 6. Share Your Experience
- Write a blog post about using this skill
- Create a tutorial video
- Share on social media with #IndonesianTechCreator

## Contribution Guidelines

### Code Style
- Use Markdown for all documentation
- Follow existing formatting
- Use Indonesian for content examples
- Keep English for technical terms

### Template Guidelines
- Include all required sections
- Provide realistic examples
- Add production notes
- Test with actual AI agents

### Workflow Guidelines
- Clear step-by-step instructions
- Include checklists
- Provide example outputs
- Add tips for Indonesian context
