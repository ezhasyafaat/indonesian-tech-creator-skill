# Title Optimization Workflow

## Overview
Generate optimized titles, descriptions, and hashtags for YouTube, TikTok, Instagram, and blog posts targeting Indonesian audience.

## Process

### Step 1: Gather Context
Ask user for:
- **Topic**: What the content is about
- **Platform**: YouTube, TikTok, Instagram, Blog, Twitter
- **Target metrics**: Views, engagement, saves, shares
- **Target audience**: Junior dev, senior dev, students, etc.
- **Keywords**: Primary and secondary keywords

### Step 2: Generate Title Variations

**For each platform, generate 5-10 title options:**

**YouTube Titles:**
- SEO-optimized + clickbait balance
- 50-60 characters (visible in search)
- Include primary keyword
- Use power words: "Tutorial", "Lengkap", "Mudah", "Cepat", "Gratis"
- Numbers work well: "5 Cara...", "10 Tips..."
- Indonesian context: "untuk Developer Indonesia", "di Indonesia"

**Examples:**
```
1. "Deploy Node.js ke Server Indonesia Cuma 50rb/Bulan! (Tutorial Lengkap)"
2. "Stop Pakai AWS! Deploy Node.js di Server Indonesia Lebih Murah 80%"
3. "Tutorial Deploy Node.js ke Biznet Gio dari A-Z (2025)"
4. "Node.js Production Setup: Deploy ke Server Indonesia (Step-by-Step)"
5. "Cara Deploy Aplikasi Node.js ke Server Lokal Indonesia (Murah & Cepat)"
```

**TikTok Titles (Hooks):**
- First 3 seconds = make or break
- Curiosity-driven
- Problem-solution format
- Short and punchy (under 10 words)
- Use "Kamu" to address viewer directly

**Examples:**
```
1. "Kamu masih deploy manual? Stop!"
2. "Deploy app cuma 50rb? Yes!"
3. "Server Indonesia vs AWS: Mana yang menang?"
4. "3 detik deploy app? Possible!"
5. "Junior dev nggak tahu ini? Rugi!"
```

**Instagram Titles:**
- For Reels: Similar to TikTok hooks
- For Carousels: Clear value proposition
- For Feed: Engaging + informative
- Include emojis for visual appeal

**Examples:**
```
1. "5 VS Code Extensions yang WAJIB Dipakai 🔥"
2. "Deploy Website Pertama Kamu (GRATIS!) 🚀"
3. "Git Tips yang Senior Dev Pakai Setiap Hari 💡"
4. "React vs Vue: Pilih yang Mana di 2025? 🤔"
5. "Roadmap Belajar Web Dev untuk Pemula 🗺️"
```

**Blog Titles:**
- SEO-optimized (include primary keyword)
- 50-60 characters for title tag
- Clear and descriptive
- Include year if relevant (2025)
- Promise value: "Panduan Lengkap", "Tutorial", "Cara"

**Examples:**
```
1. "Git Tips dan Tricks untuk Developer Indonesia: Panduan Lengkap 2025"
2. "Cara Deploy Node.js ke Server Indonesia: Tutorial Step-by-Step"
3. "5 VS Code Extensions Wajib untuk Developer Indonesia (2025)"
4. "React vs Vue vs Svelte: Perbandingan Lengkap untuk Developer Indonesia"
5. "Roadmap Belajar Web Development 2025: Dari Nol sampai Kerja"
```

### Step 3: Score Each Title

**Scoring criteria (1-10 for each):**

1. **CTR Potential**: How likely people click?
   - Curiosity gap
   - Specific numbers
   - Power words
   - Emotional trigger

2. **SEO Strength**: How well optimized for search?
   - Primary keyword included
   - Keyword position (front-loaded is better)
   - Length (not too long, not too short)
   - Secondary keywords

3. **Clarity**: Is it clear what the content is about?
   - No ambiguity
   - Clear value proposition
   - Audience knows what to expect

4. **Indonesian Relevance**: How relevant to Indonesian audience?
   - Local context
   - Indonesian keywords
   - Cultural relevance

5. **Uniqueness**: How different from competitors?
   - Unique angle
   - Not generic
   - Stands out in feed/search

**Total Score** = (CTR × 0.3) + (SEO × 0.25) + (Clarity × 0.2) + (Relevance × 0.15) + (Uniqueness × 0.1)

### Step 4: Recommend Top Choice

Present:
1. **Top 5 titles** ranked by score
2. **Recommended title** with reasoning
3. **Thumbnail text** (for YouTube/Instagram)
4. **Tags/hashtags** (platform-specific)
5. **Description first line** (first 150 characters)

## Hashtag Strategy

**Formula:**
- 5 Indonesian tech hashtags
- 5 English tech hashtags
- 3-5 niche-specific hashtags
- 2-3 trending hashtags

**Example for Git content:**
```
Indonesian: #DeveloperIndonesia #TechIndonesia #ProgrammingIndonesia #BelajarCoding #TutorialIndonesia
English: #Git #VersionControl #Programming #Coding #Developer
Niche: #GitTips #CommandLine #Terminal #GitHub
Trending: #TechTips #CodingLife
```
