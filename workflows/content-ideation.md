# Content Ideation Workflow

## Overview
Generate 10-20 content ideas based on trending topics, target audience, and unique angles for Indonesian tech content.

## Process

### Step 1: Gather Context
Ask user for:
- **Niche**: Web dev, mobile, data science, DevOps, etc.
- **Target audience**: Junior dev, senior dev, students, career switchers
- **Platforms**: TikTok, YouTube, Instagram, Blog, Twitter
- **Timeframe**: 1 week, 2 weeks, 1 month
- **Content goals**: Educational, engagement, monetization

### Step 2: Research Trending Topics
Check these sources for Indonesian tech trends:
- **Twitter/X**: Search #DeveloperIndonesia, #TechIndonesia
- **TikTok**: Discover page, tech hashtags
- **YouTube**: Trending in Indonesia, tech channels
- **LinkedIn**: Indonesian tech posts
- **Local tech news**: Tech in Asia Indonesia, e27.co
- **Community**: Discord servers, Telegram groups, Facebook groups

**Tools to use:**
- Google Trends (filter: Indonesia)
- TikTok Creative Center
- YouTube Trending
- Twitter Advanced Search

### Step 3: Filter by Relevance
For each trending topic, ask:
1. Is it relevant to target audience?
2. Can I create content about this in my niche?
3. Is there a unique Indonesian angle?
4. Is it timely (trending now or evergreen)?
5. Can I create multiple formats (video, blog, carousel)?

### Step 4: Generate Ideas
For each qualified topic, create:

```
📌 IDE #[number]: [Title]
- Format: [TikTok/YouTube/Blog/Instagram Carousel/Twitter Thread]
- Hook: [Opening line that grabs attention]
- Why trending: [Reason it's relevant now]
- Unique angle: [What makes it different from existing content]
- Estimated effort: [Low/Medium/High]
- Monetization potential: [Low/Medium/High]
```

### Step 5: Prioritize
Rank ideas by:
1. **Trending score**: How hot is the topic right now? (1-10)
2. **Relevance**: How relevant to target audience? (1-10)
3. **Uniqueness**: How unique is the angle? (1-10)
4. **Efficiency**: How easy to produce? (1-10)
5. **Monetization**: How monetizable? (1-10)

**Total score** = (Trending × 0.25) + (Relevance × 0.25) + (Uniqueness × 0.2) + (Efficiency × 0.15) + (Monetization × 0.15)

### Step 6: Output
Present top 10-20 ideas in priority order with:
- Title
- Format
- Hook
- Why it works
- Unique angle
- Effort level
- Suggested posting time

## Tips for Indonesian Audience

1. **Local context**: Reference Indonesian companies, tools, prices (Rupiah)
2. **Language**: Mix Bahasa Indonesia + English tech terms (yang umum)
3. **Pain points**: Focus on problems Indonesian developers face
4. **Price sensitivity**: "Murah", "gratis", "hemat" angles work well
5. **Community**: Reference Indonesian tech communities (Indonesia.js, Python ID, etc.)
6. **Timeliness**: Align with Indonesian holidays, events (Harbolnas, Lebaran, etc.)
